## Project Overview
This project implements a layered testbench for a 4-bit synchronous up counter using SystemVerilog.

## Design Under Test (DUT)
- 4-bit synchronous up counter
- Active-high synchronous reset
- Counts from 0 to 15 and wraps around to 0

## Testbench Architecture
1. Transaction
2. Generator
3. Driver
4. Monitor
5. Scoreboard
6. Environment
7. Top-Level Testbench

## Language
SystemVerilog

## Objective
To verify the functionality of a synchronous up counter using a modular layered verification environment.
